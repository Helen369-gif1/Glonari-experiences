# Glonari Experiences — передача проекта в новый чат

Документ для продолжения работы в новом чате. Приложить вместе с папкой проекта `glonari-experiences` (zip) и, при необходимости, `GLOBAL-DREAM-LIGHT-DESIGN-SYSTEM.md` и папкой Global Reserve.

## Что это

Одностраничный сайт «Experiences» платформы Glonari (бренд Glonari Digital Banker). Текст: `Experiences_EN.txt`, 6 экранов. Визуальная система: `GLOBAL-DREAM-LIGHT-DESIGN-SYSTEM.md` (светлая). Структура, элементы и анимация — по образцу сайта Global Reserve (тёмный, бронзовый), но в светлой палитре.

Опубликованное превью: https://claude.ai/artifact/WqPpviKRRz7U3mqttVCZcP
Рабочая версия — папка проекта: `index.html`, `css/styles.css`, `js/main.js`, `media/`. Запуск только через локальный сервер (VS Code Live Server или `python3 -m http.server 8000`), не двойным кликом.

## Порядок экранов (утверждён — структуру без запроса не менять)

1. **Introduction** — видео атриума (`media/hero.mp4`, из 1.mp4) перематывается прокруткой, секция 600vh: фазы атриума идут на прежних 320vh, интерфейсная часть растянута по просьбе заказчика (≈1,4× медленнее; константы ATRIUM_VH / IFACE_START / IFACE_VH в `main.js`). Заголовок Playfair появляется по словам, затем абзац; текст уходит до раскрытия ноутбука. В конце на экране ноутбука «загорается» тёмно-синий интерфейс (`media/ui.webp` из `ui-source-3840.png`, 16:10, окно отцентровано по вертикали), разворачивается целиком без обрезки (вписывается по высоте под шапку, по бокам продолжается тот же синий фон; на телефоне — кадр ближе к Гии). Затем **вариант Б, «тёмный мост»**: интерфейс уходит вглубь и затемняется до цвета шва `--seam: #08192A`, по словам появляется светлый заголовок экрана 2 (Playfair) и абзац. Экран 2 начинается с полосы того же цвета, панель каталога пересекает границу тёмного и светлого. Оригинальный заголовок экрана 2 остаётся в разметке визуально скрытым (для скринридеров); при «уменьшении движения» мост отключён и экран 2 показывается как раньше. Фазы по прогрессу секции: загорание .58–.63, разворот .63–.72, удержание .72–.80, затемнение .80–.88, заголовок с .84, абзац .87–.92.
2. **What Experiences means** — заголовок по центру, панель каталога: слева категории (моно-подпись CATEGORIES), поиск, фильтры статусов, 8 карточек с фото (кадры из видео) и чипами статусов. Фильтры рабочие и анимированные.
3. **Gia’s guidance** — слева видео Гии 4:5 (`media/gia.mp4` из «3 (2).mp4»: светлее и ближе к палитре, чем «3 (3)»; обрезано до 7,5 с, чтобы остановиться на спокойной улыбке) с двумя репликами, появляющимися по прокрутке; справа текст и таблица «Options from Gia».
4. **Choose and activate** — шаги 01–04 подсвечиваются по прокрутке, строка про одобрение с золотой линией слева, справа карточка одобрения (кнопки Approve / Not now работают).
5. **Пауза** (между 4 и 5, как Screen 4.5 у Global Reserve) — окно раскрывается из маленького прямоугольника, видео 5.mp4 (`media/pause.mp4`, луп «туда-обратно» 16 с), фраза «Every Experience leads here.» (Playfair), затем окно сжимается и фон уходит в графит экрана 5.
6. **Stay in control** — тёмный экран, вариант А: фон `#15181C`, панель `#1E2328`, нейтральные линии `rgba(247,243,235,.10)`, акцент шампанское золото `#D4A65F`. Панель как голограмма Global Reserve: кольцо «3 of 4 Experiences active» в центре, 4 зоны с крупными цифрами (отсчёт от нуля), строка уведомления с аватаром Гии, бегущая строка «пилюль». Подпись «Example interface — not your account.»
7. **Closing** — полноэкранное видео бассейна (2.mp4 → `media/closing.mp4`, луп «туда-обратно»), заголовок по словам, абзац, кнопка «Explore Experiences». Подвал светлый.

Шапка: логотип Glonari Digital Banker (`media/brand/logo.webp`), меню Overview / Gia / Activate / Manage, кнопки Log in и Explore Experiences.

## Решения и предпочтения заказчика

- Экраны 2–4 вернуть/держать в ПЕРВОНАЧАЛЬНОМ виде. Убраны только золотые полосы сверху на карточках. Не переделывать структуру экранов, если об этом не просили.
- Когда просят «только ответь / ничего не делай» — только отвечать, ничего не менять.
- Коричневый на коричневом не нравится; на тёмном — графит + шампанское золото (вариант А).
- Анимации — побольше, где уместно (уже добавлены: заголовки по словам, абзацы, каталог и карточки по очереди, таблица по строкам, карточка одобрения, отсчёт цифр, кольца, пульс аватара, тень шапки). Всё отключается при «уменьшении движения».
- Аватар Гии — новый портрет с улыбкой (бежевый пиджак), маленький круг 36–40 px.
- Тексты на сайте — только из `Experiences_EN.txt`; всё остальное — заглушки в квадратных скобках.

## Техника видео

- Видео, которое перематывается прокруткой: каждый кадр ключевой, без звука:
  `ffmpeg -i in.mp4 -g 1 -an -c:v libx264 -crf 27 -pix_fmt yuv420p -movflags +faststart out.mp4`
  Загружается в память через `fetch()` → blob (для мгновенной перемотки), с запасным вариантом на прямую ссылку.
- Лупы «туда-обратно» (вперёд + реверс), без звука, CRF ~25.
- Фоновые видео играют только когда видны; на мобильных и при «уменьшении движения» — постеры.
